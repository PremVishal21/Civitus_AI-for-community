# 🏛️ Civitus AI - Next.js Application Frontend

This folder contains the **Next.js 15** application for **Civitus AI: Community Intelligence & Decision Engine**.

> For full architectural documentation, system diagrams, and GCP integration details, please refer to the main [Root Repository README](../README.md).

---

## ⚡ Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production build
npm run start
```

Open [http://localhost:3000](http://localhost:3000) to view the application console.

---

## 🛠️ Stack & Modules

- **Framework**: Next.js 15.5 (App Router)
- **UI**: React 19.1 + Tailwind CSS v4
- **Animation Engine**: GSAP 3.15 + ScrollTrigger (Canvas 3D Scroll Hero)
- **Icons**: Lucide React
- **Deploy**: Vercel (`vercel.json`)
